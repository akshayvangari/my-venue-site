# Luxury Venue & Convention Website

A responsive, high-performance luxury website template inspired by the Shubhamasthu Convention prototype.

## 🚀 Quick Start

You can open and view the website immediately:

1. **Directly in Browser**:
   Double click `index.html` or open it with Google Chrome / Safari.

2. **Using Local Server** (recommended for testing smooth scrolling and fonts):
   ```bash
   cd ~/.gemini/antigravity/scratch/my-venue-site
   python3 -m http.server 3000
   ```
   Then open `http://localhost:3000` in your browser.

## 🛠 Features & Sections
- **Hero**: Atmospheric background, tagline, quick statistics, and dual call-to-actions.
- **About**: Architectural highlights, capacity statistics, and core pillars.
- **Venues**: Tabbed interactive switcher for Grand Magnum Hall and The Royal Open Lawn.
- **Stay / Rooms**: Deluxe Room, Luxury Suite, Bridal / Presidential Suite, and Family Room with amenity lists.
- **Occasions**: Weddings, Corporate Summits, Exhibitions, and Social Celebrations.
- **Gallery**: Category filter tabs (All, Venue, Celebrations, Rooms) + click-to-zoom Lightbox.
- **Reservation Form**: Form with automatic pre-filled WhatsApp inquiry integration.
- **Location & Connectivity**: ORR Exit 6 & Exit 7 connectivity cards, Google Maps embed, direct call & directions.
- **Mobile Responsive**: Custom hamburger menu drawer with smooth navigation.
