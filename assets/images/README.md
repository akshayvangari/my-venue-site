# Website Images Directory

Drop your photos into this folder (`assets/images/`) using any of the filenames below. The website will automatically display your photos! If a photo is not added yet, it falls back smoothly to a curated high-resolution sample image.

| Section | Recommended Filename | Ideal Resolution / Aspect Ratio | Description |
| :--- | :--- | :--- | :--- |
| **Hero (Main Banner)** | `hero.jpg` | 1920 × 1080 (16:9) | Front exterior or lit-up night view of the convention center |
| **About Section** | `about-featured.jpg` | 1200 × 800 (3:2) | Grand indoor entrance or floral banquet hall |
| **Magnum Hall** | `magnum-hall.jpg` | 1200 × 800 (3:2) | Column-free grand hall, stage, chandeliers |
| **Royal Open Lawn** | `royal-lawn.jpg` | 1200 × 800 (3:2) | Manicured open lawn with fairy lights or evening event |
| **Deluxe Room** | `room-deluxe.jpg` | 800 × 600 (4:3) | Deluxe guest room with king bed |
| **Luxury Suite** | `room-luxury-suite.jpg` | 800 × 600 (4:3) | Suite with separate living sofa & balcony |
| **Presidential Suite** | `room-presidential.jpg` | 800 × 600 (4:3) | Bridal / VIP suite with dressing mirror |
| **Family Room** | `room-family.jpg` | 800 × 600 (4:3) | Connected family room / multiple beds |
| **Event: Weddings** | `event-wedding.jpg` | 800 × 1000 (4:5) | Indian wedding mandap, reception stage |
| **Event: Corporate** | `event-corporate.jpg` | 800 × 1000 (4:5) | Corporate conference / summit seating |
| **Event: Exhibitions**| `event-exhibition.jpg`| 800 × 1000 (4:5) | Expo hall, stalls, trade fair |
| **Event: Cultural** | `event-cultural.jpg` | 800 × 1000 (4:5) | Sangeet, musical night, or social celebration |

> **Note**: Both `.jpg` and `.png` are supported.
